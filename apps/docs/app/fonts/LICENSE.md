# Fonts

Both families are licensed under the SIL Open Font License 1.1 and are bundled here so the site builds without
network access. The `.woff2` files are the latin subset of the variable fonts, served through `next/font/local`;
the `.ttf` files are the static weights the generated Open Graph image renders with.

| `BricolageGrotesque-ExtraBold.ttf`  | Bricolage Grotesque, static 800                                                   | OFL 1.1 |
| `JetBrainsMono-Variable.woff2`      | [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono) by JetBrains         | OFL 1.1 |
| `JetBrainsMono-Bold.ttf`            | JetBrains Mono, static 700                                                        | OFL 1.1 |
